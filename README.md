# Liberty

**El gestor del patrimonio de tu hogar. 100% local y privado.**

Liberty es una aplicación de escritorio para Windows que reúne todo el patrimonio de tu hogar
—cuentas, inversiones, inmuebles y deudas— en un solo sitio, con titulares, ingresos/gastos,
informe fiscal y multi-patrimonio. Sin cuentas, sin servidores y sin telemetría: tus datos
nunca salen de tu ordenador.

## Descarga

➡️ **[Descargar Liberty.exe](https://github.com/AlonsoVine/liberty/releases/latest/download/Liberty.exe)** (Windows, ~13 MB)

No requiere instalación. Haz doble clic en `Liberty.exe` y la app se abrirá en tu navegador
(`127.0.0.1`). Los datos se guardan en una carpeta `mis_datos` junto al ejecutable; para moverlo
a otro equipo, copia solo el `.exe`.

> La primera vez, Windows SmartScreen puede mostrar un aviso (es un `.exe` sin firma de pago).
> Pulsa **«Más información» → «Ejecutar de todos modos»**. Es normal.
